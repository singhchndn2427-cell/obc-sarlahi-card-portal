Website Name Nepal OBC Kisaan Mahasangh Create a professional, mobile-friendly website that works directly in Google Chrome and other web browsers on both iPhone and Android. 1. Admin Login & Security * Only the Admin can access the member-management section. * Admin login must be protected with a password. * Only Admin can: * Add new members * Edit member information * Delete members * Change the Admin password * Upload or change member photos * Normal visitors must not be able to access or see the Admin password or member-management controls. 2. Add Member Create an “Add Member” option available only after Admin login. When adding a member, include fields such as: * Member ID (example: OBC123) * Full Name * Address * District * Municipality/Rural Municipality * Ward No. * Phone Number * Position/Role * Member photo Allow the Admin to upload a member photo with a maximum file size of 5 MB. 3. Member Search Add a prominent Search Member box on the website. Example: * A person types OBC123 * The website searches the member database * If the ID exists, show the corresponding member’s information and photo. * If the ID does not exist, display “Member not found.” The search should be fast and work well on mobile phones. 4. Member Information Page When a valid Member ID is found, display the member’s registered information in a clean ID/profile format. Example: Member ID: OBC123 Name: [Member Name] District: [District] Municipality: [Municipality] Ward: [Ward] Position: [Position] Photo: [Member Photo] 5. QR Code Create a QR Code that contains the website address. When someone scans the QR code using their phone camera: 1. The phone recognizes the QR code. 2. They tap the link. 3. The website opens directly in Chrome/browser. 4. They can immediately use the Member Search feature. Also provide an Admin option to download/print the QR code. 6. Website Pages Include: * Home * About Nepal OBC Kisaan Mahasangh * Member Search * Member Information * Contact * Admin Login * Admin Dashboard 7. Design Use a professional, clean and trustworthy design suitable for an organization. Requirements: * Fully responsive for iPhone, Android, tablet and computer. * Easy-to-use search box. * Clear navigation menu. * Fast loading. * Secure database. * HTTPS/SSL. * Member information should only show information that the organization intends to make publicly searchable. 8. Important Security Requirement Do not store the Admin password in the website’s visible frontend code. Use secure server-side authentication and password hashing. The member database and Admin dashboard must be protected so that ordinary visitors cannot add, edit or delete members. Main Goal The final website should allow the organization to maintain its member database securely. Visitors can open the website through Chrome, enter a Member ID such as OBC123, and quickly see the corresponding registered member information. A QR code should provide an easy way to open the website.
