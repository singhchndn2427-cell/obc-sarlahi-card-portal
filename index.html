Nepal OBC Kisaan Mahasangh (नेपाल पिछडा वर्ग किसान महासंघ) # Nepal OBC Kisaan Mahasangh A mobile-friendly member verification website with: - Admin-only member management - Secure password hashing - Member IDs such as OBC123 - Public member search - Member photo upload (maximum 5 MB) - QR code for opening the website - SQLite database ## Requirements Install Node.js 18+. ## Setup 1. Open a terminal in this project folder. 2. Run: npm install 3. Copy `.env.example` to `.env`. 4. Change `ADMIN_PASSWORD` and `SESSION_SECRET` in `.env`. 5. Start: npm start 6. Open: http://localhost:3000 Default admin username: `admin` The admin password is the value you put in `.env`. ## Important before putting it online - Use HTTPS. - Change the admin password and SESSION_SECRET. - Set SITE_URL to the real HTTPS website address. - Keep `.env`, `data/`, and the `uploads/` folder private from direct file browsing. - Back up the SQLite database regularly. ## QR code The Admin Dashboard generates a QR code for the value of `SITE_URL`.
